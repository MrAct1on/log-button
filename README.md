Features
	•	Adds a persistent Logs button to the top navigation bar
	•	Navigates to Settings → Logs using a relative URL
	•	Works with any:
	•	Hostname or IP
	•	Port
	•	Reverse proxy
	•	Tunnel or sub-path deployment
	•	Automatically re-injects after SPA navigation and UI re-renders
	•	Appears to the left of RandomButton when that plugin is installed
	•	No configuration required
	•	No GraphQL usage
	•	No background polling
